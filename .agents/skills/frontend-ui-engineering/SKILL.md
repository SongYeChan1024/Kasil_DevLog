# 사용자 인터페이스 구현

1. 프로젝트의 컴포넌트와 디자인 기준을 읽고 누가 어떤 행동을 완료할 화면인지 확인합니다. 입력·로딩·빈 화면·성공·오류에서 가능한 다음 행동을 정합니다.
2. 상태 소유자를 한 곳에 두고 기존 컴포넌트를 재사용합니다. 좁고 넓은 화면, 키보드 이동, 포커스 복귀와 실제 제출 경로를 확인합니다. [화면별 접근성 체크리스트](../../../.agent-rules/upstream/references/accessibility-checklist.md)
