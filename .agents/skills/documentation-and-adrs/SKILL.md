# 문서와 설계 결정 기록

1. 독자와 기준 문서를 확인하고 기존 문서에서 바뀐 부분을 갱신합니다. 설계 결정은 배경, 고려한 대안, 선택한 이유와 결과, 상태를 남깁니다.
2. 명령·경로·예제는 현 버전에서 확인합니다. 결정이 뒤집힌 경우 이전 기록을 가리켜 변경 이유와 현재 적용 범위를 추적할 수 있게 합니다.
