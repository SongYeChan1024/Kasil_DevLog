# 중요한 가정 재검토

1. 검토할 주장을 한 문장으로 분리하고, 참이라면 관찰할 결과와 반례가 될 조건을 적습니다. 결정의 전제가 같은 출처에만 기대고 있는지 확인합니다.
2. 실제 데이터·버전·작은 독립 검사로 지지 근거와 반대 근거를 비교합니다. 주장을 유지·수정·보류한 이유와 남은 불확실성을 남깁니다. 별도 에이전트 검토는 분담 요청이 있을 때 사용합니다.
