# 프로젝트 작업 규칙

작성자: 송예찬

개인 공통 규칙은 전역 지침을 따릅니다. 아래 항목은 프로젝트의 실제 값으로 채우고, 필요 없는 항목은 삭제합니다. 팀 프로젝트라면 팀이 합의한 문서를 기준으로 작성합니다.

- 목적·작업 범위: 이 저장소의 역할과 변경 가능한 범위.
- 고유 제약: 코드만으로 알 수 없는 의존 관계, 직접 학습 순서, 담당자 경계.
- 기준 문서: 설계·수치·팀 합의의 원본 경로. 관련 작업일 때 읽을 문서를 구분.
- 현재 상태: 최신 인수인계 문서 링크. 과거 작업 기록은 그 문서에 보관.
- 검증: 변경 종류별로 실행할 실제 명령, 필요한 환경, 성공 판정 기준.
- Git 흐름: 기준 브랜치, 리뷰·병합 기준, 커밋 형식.
