# 작업 절차의 출처와 라이선스

통합·조정 문서 작성자: 송예찬

`shared-intent`, `shared-spec-plan`, `shared-quality`는 [Addy Osmani의 agent-skills](https://github.com/addyosmani/agent-skills)의 interview-me, spec-driven-development, constraint-driven-development와 도입 안내를 참고하여 현재 사용자 지침과 프로젝트 방침에 맞게 작성했습니다. 검토한 upstream 기준은 `8c99fa36d90068c82d547f7c12a9d67a3e95f4ee`입니다.

사용자 진행 지시·위임을 인정하며, 반복 승인·임의 확신 수치·확인 후 강제 턴 종료·프로젝트에 맞지 않는 일괄 수치 기준은 채택하지 않았습니다. 원본 패키지 전체나 그 자동 실행 절차를 설치한 것은 아닙니다. 원본을 재검토할 때에도 현재 합의와의 차이를 검토한 뒤 반영합니다.

원본 라이선스와 저작권 고지는 아래에 보존합니다. 생성되는 각 프로젝트의 `.agent-rules/THIRD_PARTY_NOTICES.md`에도 같은 고지를 포함합니다.
