# 작업 절차의 출처와 라이선스

통합·조정 문서 작성자: 송예찬

[Addy Osmani의 agent-skills 고정 버전](https://github.com/addyosmani/agent-skills/tree/8c99fa36d90068c82d547f7c12a9d67a3e95f4ee)에 있는 스킬 26개를 같은 이름의 한국어 절차로 정리했습니다. 기존 `shared-intent`, `shared-spec-plan`, `shared-quality`에는 프로젝트에서 합의한 판단 기준을 유지합니다. 각 스킬에 해당 버전의 원문 링크가 있습니다.

관리 원본의 `tools/agent-rules/upstream/`과 설치본의 `.agent-rules/upstream/`에는 원본 [공용 참고 문서 7개](https://github.com/addyosmani/agent-skills/tree/8c99fa36d90068c82d547f7c12a9d67a3e95f4ee/references)와 [인터뷰 평가 사례](https://github.com/addyosmani/agent-skills/blob/8c99fa36d90068c82d547f7c12a9d67a3e95f4ee/evals/cases/interview-me.json)를 수록합니다. 이 자료의 저작권 및 MIT 라이선스는 아래와 같습니다.

사용자 진행 지시·위임을 인정하며, 반복 승인·임의 확신 수치·확인 후 강제 턴 종료·프로젝트에 맞지 않는 일괄 수치 기준은 채택하지 않았습니다. 원본 패키지 전체나 그 자동 실행 절차를 설치한 것은 아닙니다. 원본을 재검토할 때에도 현재 합의와의 차이를 검토한 뒤 반영합니다.

원본 라이선스와 저작권 고지는 아래에 보존합니다. 생성되는 각 프로젝트의 `.agent-rules/THIRD_PARTY_NOTICES.md`에도 같은 고지를 포함합니다.
